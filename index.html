Frequently asked questions

Some useful information about Toursaza.

Are the listed tours real bookings? ＋
No. The tours and prices currently shown are sample demonstration data. A live travel provider or your own inventory system is required for actual availability and bookings.
Where does the country list come from? ＋
The country directory is loaded dynamically from the REST Countries API v5.
Can I book and pay online? ＋
Not in this frontend demo. A backend, booking provider integration and payment gateway are required before real bookings and payments can be accepted.
Can I request a custom trip? ＋
You can use the booking enquiry form to describe a trip. In this demo, the form only displays a local confirmation and does not send the enquiry to a business.
